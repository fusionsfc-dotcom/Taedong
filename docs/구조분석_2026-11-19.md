# 춘천태동요양병원 홈페이지 구조 분석 (2026-11-19)

업데이트 작업에 앞서 현재 저장소를 읽고 정리한 문서다. 기존 `PROJECT_STRUCTURE.md`는 2026년 3월 기준이라 라우트·섹션 순서·사이트맵 내용이 현재 코드와 다르다.

## 1. 기술 스택과 배포

| 항목 | 내용 |
|---|---|
| 출처 | Figma Make 내보내기 (커밋 4건, 모두 figma[bot]) |
| 빌드 | Vite 6.3.5 + React 18.3.1 + TypeScript (tsconfig 없음) |
| 라우팅 | react-router 7.13.0, `createBrowserRouter` |
| 스타일 | Tailwind CSS 4.1.12 + 인라인 style. 브랜드 색은 파일마다 hex로 직접 기입 |
| 애니메이션 | motion 12 (`motion/react`) |
| 아이콘 | lucide-react |
| 배포 | Vercel (`vercel.json`으로 SPA 리라이트), 도메인 `www.taedonghp.co.kr` |
| 폰트 | `fonts.css`가 비어 있어 시스템 기본 폰트 사용 |

실제로 쓰는 외부 패키지는 `motion`, `lucide-react`, `react-router` 셋뿐이다. MUI, recharts, react-dnd, react-slick, embla, react-hook-form, date-fns와 `components/ui/`의 shadcn 컴포넌트 50개는 어디에서도 import하지 않는다.

## 2. 라우트 구조 (`src/app/routes.ts`)

```
/robots.txt        RobotsTxtPage      (Layout 없음, 실제로는 vercel.json이 public/robots.txt를 먼저 서빙)
/sitemap.xml       SitemapXmlPage     (위와 같음)
/                  Layout = TopNav + <Outlet/> + BottomNav
  ├ /                   LandingPage        12개 섹션 스토리텔링
  ├ /room-detail        RoomDetailPage     입원실
  ├ /environment-detail EnvironmentDetailPage 자연환경
  ├ /medical-detail     MedicalDetailPage  치료재활
  ├ /food-detail        FoodDetailPage     식사
  ├ /non-reimbursable   NonReimbursablePage 비급여 가격표
  ├ /sitemap            SitemapPage        URL 목록 HTML
  ├ /robots             RobotsPage         robots 내용 HTML
  └ /*                  NotFoundPage       404 (내부에 robots/sitemap 분기 코드가 또 있음)
```

## 3. 공통 레이아웃

- **TopNav**: 홈(`/`)에서는 숨김. 상세 페이지에서만 병원명 + 홈 버튼. 상세 페이지는 각자 `paddingTop`으로 겹침을 피한다.
- **BottomNav**: 하단 고정 6탭. 입원실 / 자연환경 / 치료재활 / 식사 / 비급여 / 병원소식.
- **CTASection**: 모든 페이지 맨 아래에 반복. 메뉴 6개 + 전화 버튼 + 구글 지도 iframe + 연락처.
  - 전화 `tel:1522-0288`, 표기 `1522-0288 | 033-263-8110`
  - 주소 `강원도 춘천시 남면 박암관천길 821`
  - 연락처·주소는 이 파일 한 곳에만 있어 수정이 쉽다.
- 메뉴 목록이 `BottomNav.tsx`와 `CTASection.tsx`에 따로 하드코딩되어 있다. 메뉴를 바꾸면 두 파일을 함께 고쳐야 한다.

## 4. 랜딩 페이지 섹션 (렌더 순서)

| 순서 | 컴포넌트 | 앵커 id | 핵심 메시지 |
|---|---|---|---|
| 1 | HeroSection | 없음 | 도심과 멀어질수록, 건강에 더 가까워집니다 |
| 2 | RealitySection | reality-section | 지금, 어디에서 회복하고 계신가요? |
| 3 | EnvironmentSection | environment-section | 암이 생겼던 생활 속으로 아무런 준비없이 돌아 가셨나요? |
| 4 | NatureRecoverySection | nature-recovery-section | 자연 속 회복 |
| 5 | MedicalBalanceSection | medical-balance-section | 자연 속이라고, 의료가 약해지면 안 됩니다 |
| 6 | RoomSection | room-section | 집처럼 편안하지만, 집보다 건강한 공간 |
| 7 | DailyFlowSection | daily-flow-section | 다시 살아나는 하루의 흐름 |
| 8 | GuardianSection | guardian-section | 회복은 식사에서 완성됩니다 |
| 9 | QASection | qa-section | 자주 묻는 질문 11개 (아코디언) |

모든 문구는 JSX 안에 직접 적혀 있다. 별도 데이터 파일이나 CMS는 없다. 섹션마다 `window.addEventListener('scroll')`을 따로 걸어 등장 애니메이션을 제어한다.

## 5. 상세 페이지 공통 패턴

4개 상세 페이지(입원실·자연환경·치료재활·식사)는 같은 뼈대다.

- `useSEO()`로 title / description / canonical 설정
- `data-section` 블록을 세로로 나열, 스크롤 감지로 `activeSection` 갱신
- 풀폭 이미지 + 제목 + 본문 2~3줄 반복
- 끝에 `<CTASection />`

비급여 페이지는 이미지 없이 카드형 가격표 10개 섹션이다. 가격 데이터는 페이지 파일 안의 배열에 들어 있다.

## 6. 콘텐츠 자산 현황

| 종류 | 수량 | 상태 |
|---|---|---|
| `figma:asset/*.png` (병원 실사진) | 34개 | **저장소에 없음.** `src/assets/` 폴더 자체가 없다 |
| Unsplash 외부 이미지 | 7개 | 핫링크. 히어로, 치료재활 1장, 식사 5장 |

`vite.config.ts`의 `figmaAssetResolver`가 `figma:asset/` 경로를 `src/assets/`로 돌리지만 파일이 없어 **`vite build`가 즉시 실패한다**(RoomDetailPage의 첫 이미지에서 ENOENT). 이 저장소만으로는 로컬 실행도 배포도 되지 않는다. 운영 중인 사이트는 Figma Make 쪽에서 자산을 포함해 배포했을 가능성이 크다.

## 7. SEO 구성과 불일치

- `useSEO` 훅이 페이지마다 title / description / canonical / robots를 `document.head`에 넣는다.
- 랜딩 페이지만 JSON-LD(`Hospital`)를 넣는다. 전화번호·도로명 주소는 빠져 있다.
- `index.html`은 `lang="en"`, meta description·OG 태그 없음. SPA라 초기 HTML에 본문이 없어 네이버 수집에 불리하다.

canonical 불일치:

| 페이지 | 실제 경로 | canonical 값 |
|---|---|---|
| 랜딩 | `/` | `https://www.taedonghp.co.kr/` |
| 입원실 | `/room-detail` | `https://taedonghp.co.kr/rooms` (www 없음, 존재하지 않는 경로) |
| 자연환경 | `/environment-detail` | `https://taedonghp.co.kr/environment` |
| 치료재활 | `/medical-detail` | `https://taedonghp.co.kr/medical` |
| 식사 | `/food-detail` | `https://taedonghp.co.kr/food` |
| 비급여 | `/non-reimbursable` | `https://taedonghp.co.kr/non-reimbursable` (www 없음) |
| robots 페이지 | `/robots` | `/sitemap`을 가리킴 |

robots / sitemap이 네 군데에 중복되어 있다: `public/` 정적 파일, `RobotsTxtPage`·`SitemapXmlPage` 라우트, `NotFoundPage` 내부 분기, `RobotsPage`·`SitemapPage` HTML 페이지. Vercel이 정적 파일을 먼저 돌려주므로 React 쪽 세 벌은 실행되지 않는 코드다. React 쪽 robots 내용은 `Sitemap:` 값으로 HTML 페이지인 `/sitemap`을 가리킨다. `public/sitemap.xml`에는 `lastmod`가 없다.

## 8. 바로 눈에 띄는 결함

1. **빌드 실패**: 병원 사진 34장이 없다. 업데이트 전에 Figma Make에서 자산을 받아 `src/assets/`에 넣거나, 운영 사이트 빌드 산출물에서 회수해야 한다.
2. **병원소식 버튼이 죽어 있음**: BottomNav와 CTASection의 '병원소식'은 `news-section` 앵커로 스크롤하지만 그 id를 가진 요소가 어디에도 없다. 눌러도 아무 일이 없다.
3. canonical URL이 실제 경로·도메인과 다르다 (7절).
4. 비급여 표에서 `바이온주`가 60,000원과 120,000원으로 두 번 나온다. 용량 구분이 빠진 것인지 확인이 필요하다.
5. 저장소 위생: `.gitignore`가 없어 `node_modules/`, `.DS_Store`가 untracked로 뜬다. 문서는 pnpm을 말하지만 `package-lock.json`(npm)이 생성돼 있다. `tsconfig.json`이 없다.
6. 디자인 토큰 부재: `theme.css`는 shadcn 기본값이고, 브랜드 색(`#3F6B4F`, `#1E3A2E`, `#2E5D46`, `#F7F6F3`, `#E8E6E0`)은 각 파일에 흩어져 있다. 색을 바꾸려면 전 파일을 뒤져야 한다.
7. 미사용 의존성 약 45개와 shadcn UI 50개 파일이 설치 시간과 혼란만 만든다.
